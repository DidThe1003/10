# Ugly 10

Ugly 10 is a probability based game forked from 10. You start with a 1 (probably) and you have to fill up boards by holding down the arrow keys.

The objective of the game is to figure out which tiles you think.

The game spawns all the tiles with increasing rarity. The most notable one is 33 (beak).

As far as I am aware, the rarest tile that has ever been had is 10000, sitting at 1 in every 10000000 (10 million) tiles.

Good luck, luck is all you need!
